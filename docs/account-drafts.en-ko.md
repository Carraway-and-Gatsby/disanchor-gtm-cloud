# 계정별 초안 14개 · English / 한국어

검토용 문서 · 2026-10-25. 앞서 제시한 영문 14개를 그대로 보존하고 한국어 번역을 붙였습니다. [계정별 프롬프트](account-strategies.md)와 함께 검토하세요.

**실제 게시 없음 · API 게시 OFF · 전체 예산 USD 20 유지.** 이 문서 저장, 번역 검토, 체크 표시 또는 GitHub 업로드는 게시 승인이 아닙니다. 게시 대기열·DB·예약에는 넣지 않았습니다. 계정의 설정 언어는 영어이며 한국어는 검토용 번역입니다.

개발 중이라는 점을 각 글의 맥락에 넣었습니다. 제품이 이미 제공하는 기능이나 실제 고객 성과를 주장하지 않습니다. 링크·판매 유도·해시태그·계정 간 복제 없이 서로 다른 소재를 사용합니다. 같은 개발 배경을 여러 계정에서 계속 반복하면 광고처럼 느껴질 수 있으므로, 14개를 일괄 배포하는 계획으로 해석하지 않습니다.

## Instagram · @disanchor_com

전략 키: `default_instagram` · 접근: 장면으로 보여 주는 일상적인 작업 환경 · [적용 프롬프트](../prompts/accounts/default_instagram.md).

현재 워커는 Instagram 전송을 지원하지 않습니다. 아래 장면은 촬영·디자인 제안이며 실제 이미지는 만들지 않았습니다.

### IG-01

장면 제안: 오래된 프린터와 새 노트북이 함께 놓인 책상.

**English**

> An old printer can outlive three laptops. While we're building Disanchor, this is a useful reminder: a work setup includes the things plugged into it, not just the machine on the desk.

**한국어 번역**

> 오래된 프린터 하나가 노트북 세 대를 바꿔 쓰는 동안 계속 쓰이기도 합니다. Disanchor를 만들면서 떠올리는 점입니다. 작업 환경에는 책상 위 컴퓨터뿐 아니라 거기에 연결된 기기들도 포함됩니다.

### IG-02

장면 제안: 같은 문서의 줄바꿈이 다르게 표시된 두 화면. 제품 화면 대신 일반적인 문서 예시 사용.

**English**

> Same document, different line breaks. Disanchor is still in development, and a missing font is a small example of how a familiar task can change before any work begins.

**한국어 번역**

> 같은 문서인데 줄바꿈은 다릅니다. 아직 개발 중인 Disanchor를 생각할 때, 글꼴 하나가 없다는 작은 차이만으로도 익숙한 작업이 시작 전부터 달라질 수 있다는 점을 돌아보게 됩니다.

## X · @guidances_org

전략 키: `default_x` · 접근: 독자가 직접 해 볼 수 있는 점검 · [적용 프롬프트](../prompts/accounts/default_x.md).

### DX-01

**English**

> If a file opens but won't save, check where it's stored before reinstalling the app. We're developing Disanchor, and separating permissions from application problems keeps the investigation focused.

**한국어 번역**

> 파일이 열리는데 저장이 안 된다면 앱을 다시 설치하기 전에 저장 위치부터 확인해 보세요. Disanchor를 개발하면서도 접근 권한 문제와 앱 자체의 문제를 구분하면 원인을 더 집중해서 살펴볼 수 있다는 점을 생각합니다.

### DX-02

**English**

> A task that works alone but stalls beside two other apps needs a different test from one that is always slow. As we build Disanchor, we're keeping workload and machine specs as separate questions.

**한국어 번역**

> 혼자 실행할 때는 괜찮다가 다른 앱 두 개와 함께 쓰면 느려지는 작업은, 언제나 느린 작업과는 다르게 시험해야 합니다. Disanchor를 만들면서 작업 부하와 컴퓨터 사양을 별개의 질문으로 살펴보고 있습니다.

## LinkedIn · 게시 대상 확인 필요

전략 키: `personal_linkedin` · 접근: 업무 방식과 설계 선택 · [적용 프롬프트](../prompts/accounts/personal_linkedin.md).

연결된 사람과 선택된 회사 Page 중 실제 게시 주체를 다시 확인해야 합니다. 개인 경험을 지어내지 않도록 중립적인 문장으로 썼으며 현재 워커는 LinkedIn 전송을 지원하지 않습니다.

### LI-01

**English**

> A team can standardize software versions without standardizing every working preference. Disanchor is still in development, and the distinction matters: consistency can make support easier, while some variation helps people do their jobs. The useful boundary is what needs to be shared, and what can remain personal.

**한국어 번역**

> 팀이 소프트웨어 버전을 통일한다고 해서 각자의 작업 취향까지 모두 통일해야 하는 것은 아닙니다. 아직 개발 중인 Disanchor를 생각할 때도 이 구분은 중요합니다. 일관성은 지원을 쉽게 만들 수 있지만, 어느 정도의 차이는 각자가 일하는 데 도움이 됩니다. 무엇을 함께 맞추고 무엇을 개인에게 남길지가 유용한 기준입니다.

### LI-02

**English**

> A handover document is easier to judge when the original author is unavailable. While Disanchor is being developed, that is a useful lens for workspace design: could someone identify the required tools, understand the dependencies, and know which decisions need an owner? Installation alone does not answer those questions.

**한국어 번역**

> 인수인계 문서는 작성자에게 물어볼 수 없을 때 더 제대로 평가할 수 있습니다. 개발 중인 Disanchor의 작업 환경 설계에도 적용해 볼 만한 관점입니다. 필요한 도구를 알아낼 수 있는지, 도구 사이의 의존 관계를 이해할 수 있는지, 어떤 결정에 담당자가 필요한지 알 수 있는지 살펴보는 것입니다. 설치를 끝냈다는 사실만으로는 이 질문에 답할 수 없습니다.

## 공식 X · @disanchor_com

전략 키: `disanchor_x` · 접근: 기술적 제약과 검증 방법 · [적용 프롬프트](../prompts/accounts/disanchor_x.md).

### OX-01

**English**

> For Disanchor's ongoing development, 'reconnect' needs a testable definition: after a network interruption, does the app keep running, does unsaved work remain, and what state does the user actually return to?

**한국어 번역**

> 개발 중인 Disanchor에서 ‘재연결’은 시험할 수 있는 말로 정의해야 합니다. 네트워크가 끊긴 뒤에도 앱은 계속 실행되는지, 저장하지 않은 작업은 남는지, 사용자는 실제로 어떤 상태로 돌아오는지를 확인해야 합니다.

### OX-02

**English**

> An idle session and an abandoned session can look identical from a server. While we're building Disanchor, any proposed cleanup rule needs to be tested against work that is quiet but still in progress.

**한국어 번역**

> 서버에서는 잠시 쉬고 있는 세션과 더 이상 쓰지 않는 세션이 똑같아 보일 수 있습니다. Disanchor를 만들면서 제안하는 세션 정리 규칙은, 조용하지만 여전히 진행 중인 작업에도 적용해 시험해야 합니다.

## 검토 포인트

- 영문과 번역의 의미가 맞는지, 해당 계정의 말투와 독자 가설에 맞는지 확인합니다.
- 실제로 확인한 경험·사실만 남기고, 개인 계정의 1인칭 표현은 실제 작성자 관점과 일치하는지 확인합니다.
- 개발 중인 제품에 대한 문제 제기와 이미 구현된 기능의 주장을 혼동하지 않는지 확인합니다.
- 최근 게시물·다른 계정 글과 소재와 표현이 겹치면 새 글로 다시 작성합니다. 개발 고지의 위치만 바꾸어 중복 검사를 피하지 않습니다.
- 플랫폼 정책·경고·권한·계정 ID·할당량·비용 검토를 통과하기 전에는 게시하지 않습니다. 게시량 제한은 안전을 보장하는 플랫폼 허용치가 아닙니다.
