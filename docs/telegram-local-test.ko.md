# Telegram 로컬 상태·초안 확인 결과

2026-10-25 · Cloud 인스턴스 생성 없이 기존 전용 봇 `@disanchor_gtm_bot`과 소유자의 개인 대화에서 테스트했습니다. 총예산 $20, API 게시 OFF, LinkedIn 게시 차단을 유지했습니다.

| 점검 | 확인 결과 |
| --- | --- |
| 봇 신원·webhook | 기존 봇 신원 확인, webhook 없음. 변경하지 않음 |
| 로컬 상태 전달 | Bot API 전송 성공. Cloud 미생성·실험 준비·게시 OFF·예산을 표시 |
| 영어 초안 전달 | Threads `@disanchor_com` 검토 초안 2개 전송 성공. 자동 테스트 메시지이며 수신 명령을 꾸미지 않음 |
| `/status` | 허용한 본인 개인 대화의 실제 명령 수신 및 응답 전송 성공 |
| `/drafts personal_threads` | 실제 명령 수신 및 한국어 초안 2개 응답 전송 성공. 운영·재연결 보류 표시 |
| `/drafts default_threads` | 이 명령의 수신 기록 없음. 자동 영어 초안 전달과 구분하며 명령 왕복 완료로 주장하지 않음 |
| 휴대폰 확인 | 소유자가 응답 수신을 확인했다고 답함. 서버에서 확인한 실제 명령은 위의 2개 |
| 종료 | 5분 제한으로 종료, 상시 listener 없음, `telegram.enabled=false` 유지 |

서버 기록은 Telegram API 호출 48회, 전송 성공 5건(로컬 상태·영어 초안·최초 상태 알림·실제 명령 응답 2건), UNKNOWN/실패 전달 0건입니다. 이 테스트의 3명령 완료 조건 중 2개를 확인했으므로 비공개 결과에는 `bounded_test_finished_owner_commands_incomplete`로 기록했습니다. 상태 조회와 한국어 초안 조회의 실제 왕복, 영어 초안의 실제 전달은 각각 확인됐습니다. 모든 조회 명령의 실제 왕복을 검증했다는 뜻은 아닙니다.

실험 상태는 `NEW`이며 시작·승인하지 않았습니다. 실험 레코드, 게시 초안·게시 작업·비용 원장 건수가 테스트 전후 같음을 검사했습니다. SNS 게시·예약·수집 API 및 모델 호출은 0회입니다. Telegram 수신 offset과 응답 outbox만 비공개 DB에 저장했습니다. Cloud·cron·추가 과금 서비스를 생성하지 않았으며, 이 시험에서 모델·도구 비용은 발생시키지 않았습니다. 실제 Cloud 요금 검증·Cloud 재시작 복구는 아직 수행하지 않았습니다.

초안 조회는 버전을 고정한 공개 문서를 읽으며 게시 대기열에 넣지 않습니다. Telegram으로 게시·승인·예산 변경·shell 실행을 할 수 없습니다. 토큰·숫자형 개인 ID·DB·전체 원본 응답은 이 문서와 Git에 포함하지 않았습니다.

오프라인 검증: 전체 427개 테스트, 안전한 소스 기본값 점검, 자격증명 없는 staging smoke 통과. 기존 비밀값이 공개 소스에 포함되지 않는지도 비교 검사했습니다.

다시 테스트할 때는 [Telegram 운영 안내](telegram.md#cloud-생성-전-로컬-연결-테스트)의 제한 실행 명령을 사용합니다. 봇은 로컬 실행 중에만 응답하며, 이 결과는 Cloud 배포 완료를 뜻하지 않습니다.
